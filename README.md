# LanShare — اشتراک فایل روی وای‌فای محلی

برنامهٔ وب برای ارسال فایل بین همکاران روی **همان شبکه WiFi**، بدون اینترنت و بدون نصب اپ.

## پیش‌نیازها

- Windows با **SQL Server** (روی سیستم شما Express در حال اجراست)
- **.NET 8 SDK**
- **Node.js** (برای ساخت رابط کاربری)

## راه‌اندازی سریع (سرور = همین کامپیوتر)

### روش ساده (پیشنهادی)

1. **یک بار:** روی `باز-کردن-فایروال.bat` کلیک راست → **Run as administrator**
2. دوبار کلیک روی `اجرا-سرور.bat` (پنجره را نبندید)
3. آدرس `http://IP-شما:5080` را روی **گوشی و PC همکاران** در مرورگر باز کنید
4. هر نفر **نام خود** را وارد کند
5. در تب «همکاران»، طرف مقابل را انتخاب کنید → «انتخاب و ارسال فایل»

### روش PowerShell

```powershell
cd "d:\APP\Cursor test\LanShare\scripts"
.\start-server.ps1
```

### اگر از گوشی وصل نمی‌شود

فایروال ویندوز باید پورت **5080** را باز کند (`باز-کردن-فایروال.bat` با Run as administrator).

## نکات مهم

- همه باید به **همان وای‌فای** وصل باشند.
- سرور باید **روشن** بماند؛ با بستن PowerShell سرویس قطع می‌شود.
- حداکثر حجم هر فایل: **۵۰۰ مگابایت** (در `appsettings.json` قابل تغییر).
- فایل‌ها روی سرور ذخیره می‌شوند و پس از دانلود در تاریخچه می‌مانند.

## ساختار

- `backend/LanShare.Api` — ASP.NET Web API + SignalR + SQL Server
- `frontend` — React (فارسی، موبایل‌فرندلی)
- پورت پیش‌فرض: **5080**

## عیب‌یابی

| مشکل | راه‌حل |
|--------|--------|
| صفحه باز نمی‌شود | IP را از خروجی اسکریپت بگیرید؛ فایروال پورت 5080 |
| «اتصال برقرار نشد» | سرور روشن است؟ همان WiFi؟ |
| خطای دیتابیس | SQL Server Running باشد؛ دیتابیس `LanShare` خودکار ساخته می‌شود |
